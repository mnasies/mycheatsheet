# Application Icon License & Attribution

## Design Motif
The `mycheatsheet` application icon combines an open reference handbook with a terminal command prompt (`>_`) and syntax-highlighted code lines, mirroring the offline cheatsheet nature of the tool.

- **Colors**:
  - Background: Deep warm dark sepia (`#181411` to `#2a241f`)
  - Pages: Warm paper (`#f4ecd8`)
  - Accents: Terracotta brand color (`#b85437` / `#8e3d25`)
  - Syntax tokens: Editorial red (`#a32d18`), green (`#2b6838`), brown (`#9c5c16`)
